# ARKAM · Custom Guitar Picks — preview web

Propuesta de sitio para [@arkam_arg](https://www.instagram.com/arkam_arg/): configurador de púas (modelo, espesor, colores, grabado simple/doble faz, color de grabado y terminación) que arma un resumen del pedido para enviar por Instagram.

Es un único archivo `index.html` (HTML + CSS + JS, sin dependencias).
